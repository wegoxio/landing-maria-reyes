# Currículum

Coloca aquí el currículum en PDF con el nombre exacto que espera la página
`/about`:

```
cv-maria-del-carmen.pdf
```

El botón **«Descarga mi currículum»** de la sección «Sobre mí» apunta a
`/files/cv-maria-del-carmen.pdf`. Mientras el archivo no esté en esta carpeta,
el enlace devuelve un 404.
